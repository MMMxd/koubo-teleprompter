## 口播工坊 v4.6 · 首个开源版本

一体化 AI 口播工作台：**AI 写稿 → 全网热点 → 全屏/悬浮提词 → 语音跟随**

### 📦 下载
- `koubo-teleprompter-v4.6.apk`（95MB，**内置离线语音模型**，下载即装）
- 要求 Android 6.0+，arm64 真机（x86_64 模拟器亦可）

### ✨ 功能亮点
- 🤖 **AI 三步写稿**：选角色 → 3 个方向 → 一键成稿；DeepSeek 或任意 OpenAI 兼容接口，Key 在「我的」页自填
- 🔥 **五平台热搜聚合**：抖音 / 百度 / 头条 / B站 / 微博，热点标题一键带进创作简报
- 📺 **全屏提词**：金色定位线 + 速度/字号/透明度三滑杆实时调
- 🎥 **悬浮提词**：挂相机 App 上层，边拍边念不切屏
- 🎙️ **离线语音跟随**：sherpa-onnx 中文流式识别（模型在 APK 内），念到哪滚到哪，当前句琥珀高亮
- 📚 **稿件库**：本地管理、编辑、分享、一键提词

### 🔒 隐私
免账号、无后端、数据只存本机；仅 AI 生成与抓热搜联网，且直连你配置的接口。

## Koubo Teleprompter v4.6 · First open-source release

All-in-one AI teleprompter studio for spoken-video creators: AI script writing via DeepSeek / any OpenAI-compatible API, 5-platform hot-search aggregator (Douyin/Baidu/Toutiao/Bilibili/Weibo), full-screen & camera-overlay floating teleprompter, offline voice-follow scrolling powered by sherpa-onnx (model bundled in APK).

**Install**: Android 6.0+, arm64 devices. No account needed, no backend — your data stays on device.
